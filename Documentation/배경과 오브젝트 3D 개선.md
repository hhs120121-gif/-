# 배경과 오브젝트 3D 개선

## 반영 내용

기존 격자판 위에 단순 도형이 놓인 인상을 줄이고, 캐릭터가 실제 실내에서 움직이는 공간으로 구성했다. 원본 `resources`와 기존 이야기·제작·전투 규칙은 보존했다.

| 제안 | 실제 구현 |
| --- | --- |
| 공방을 기준 공간으로 정비 | 생활 공간의 목재 단상, 낮은 칸막이, 중앙 제작대와 작업 매트, 뒤쪽 보관 선반으로 구역을 구분 |
| 인체 기준 크기 | 침대·책상·제작대·단말기·문을 캐릭터 크기에 맞춘 전용 메시로 교체하고 충돌 범위 조정 |
| 구조와 두께 | 가구 다리, 프레임, 서랍, 손잡이, 공구판, 바이스, 패널 틈, 볼트, 침구 주름과 두께 구현 |
| 바닥 | 반복 격자 타일 제거, 연속 콘크리트 바닥과 목재 생활 구역, 작업·보관 구역, 제한된 통행 표시 적용 |
| 재질 구분 | 목재 결, 천 조직, 콘크리트 표면 변화, 금속 반사, 고무의 낮은 광택, 투명 유리와 용기 내부 액체 적용 |
| 건축 깊이 | 두께 있는 벽, 창턱·창틀·멀리언·인방, 문 주변 벽체, 기둥, 걸레받이, 천장 보와 서비스 배관 추가 |
| 창밖 원근 | 창밖 건물과 창문을 실제 별도 깊이에 배치해 카메라 이동에 따른 시차 제공 |
| 조명 | 따뜻한 주광, 작업대 스포트라이트, 실내 보조광, 부드러운 실시간 그림자로 형태와 접지감 강화 |
| 카메라 | 낮춘 사선 원근 카메라, 이동 방향 선행, 대화 시 부드러운 접근, 화면 기준 이동 방향 적용 |
| 가림 처리 | 머리·몸통·발 높이로 가림을 검사해 벽·보·큰 가구가 플레이어를 가리면 디더 페이드 적용 |
| 전체 구간 확장 | 14개 맵에 공통 모델 키트 적용, 초기 공방·손상 구역·격리 구역·후반 연구실의 구조 장식 구분 |

## 제작 파일

- `ArtSource/Environment/EnvironmentKit.blend`: 편집 가능한 모델 원본.
- `ArtSource/Environment/build_environment.py`: 모델 제작 및 FBX 출력 재현 스크립트.
- `Assets/Game/Resources/Environment/`: 가구·장비 등 14종과 건축용 베벨 메시.
- `Assets/Game/Scripts/Runtime/Environment3D.cs`: 모델 로딩, 재질, 건축 구성과 가림 처리.
- `Assets/Game/Resources/EnvironmentSurface.shader`, `EnvironmentGlass.shader`: 표면 및 투명 유리 재질.

## 검증과 범위

- Unity 3D 검증: 14개 맵, 맵당 최소 197개 메시 렌더러, 94개 오브젝트 충돌체, 42개 주요 인물 배치 통과.
- 최신 출입구 구조 포함 이동 검증: 14개 맵의 상호작용 대상 94개 모두 접근 가능.
- 환경·카메라 변경 후 이야기 진행 검증: 16개 체크포인트 통과.
- 실제 Unity 화면: `Tools/verification-environment-workshop.png`, `Tools/verification-environment-lab.png`.
- Windows 빌드 및 실행 검증 결과: `Tools/build-report.json`, `Builds/Windows/Verification/runtime-report.json`.
- 최종 Windows 빌드 오류 0·경고 0, 실행 검사 PASS·오류 0. 숨김 창의 검은 캡처를 발견해 일반 창으로 재실행했으며, `Builds/Windows/Verification/workshop.png`에서 실제 공방 렌더링을 확인했다.

이번 자산은 Blender 메시와 절차적 표면 재질로 제작했다. 수작업 고해상도 조각·사진 기반 PBR 텍스처 제작, 베이크 GI, 저사양 기기별 성능 측정까지 완료했다는 의미는 아니다. 자동 검증은 충돌·진행·자산 누락을 확인하며 미술 완성도에 대한 사용자 평가를 대신하지 않는다.
