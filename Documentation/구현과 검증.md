작성일: 2026년 9월 26일

> 후속 변경: 사용자의 3D 전환 지시를 반영했다. 아래 표의 도트 월드·640×360 카메라·스프라이트 설명은 이전 구현 기록이다. 현재 그래픽 구조와 검증 범위는 `3D 전환 기록.md`를 우선 참조한다.

## 반영 원칙

원본 resources의 두 DOCX와 세 캐릭터 시트는 변경하지 않았다. `바이러스의 비밀_상세 게임 제작 기획서.md`의 상세 제안을 기본 제작안으로 채택해 Unity 프로젝트에 게임 진행을 구현했다.

현재 결과물은 처음부터 네 엔딩까지 연결되는 플레이 가능한 게임이다. 문서의 목표 플레이 시간과 완성품 수준의 재미·연출 품질까지 자동 검사만으로 달성했다고 판단하지 않는다. 규칙 구현, 실행 검증, 사람이 평가할 경험을 아래에서 구분한다.

## 이번 구현에서 확정한 규칙

1. 동생은 다은의 동생이다. 이름·성별·나이는 임의로 확정하지 않았다.
2. 배급약은 임시 억제제이고 V-06은 완치 치료제다. 도입부의 치료 성공은 G.M.R.I.의 공식 발표다.
3. 필드에서는 현재 리더 한 명을 표시한다. 파티는 공유 HP를 사용한다.
4. 다니엘의 제압은 기본 +30, 30% 확률로 +15다. 방패가 올라간 적은 기본 증가량이 절반이다.
5. 올바른 설득은 기본 +25이며 추가 공감 +10의 확률은 기본 20%, 제임스 55%다.
6. 제임스의 분석 공격 보정은 다음 턴에만 유효하고 중첩하지 않는다. 같은 페이즈에서 반복 분석해 설득량을 무한히 얻을 수 없다.
7. A 조각은 우회 후 돌아와 회수할 수 있다. B의 잘못된 최종 주입은 경고·확인 후 조각 획득을 영구 차단한다. C는 협상·전투 모두 조각 획득이 가능하다.
8. 주민 구조 자체는 적대 사건이 아니므로 전투 비율에 포함하지 않는다. 연구원 C의 협상은 지정된 적대 사건의 평화 해결로 포함한다.
9. 자동 보안 장치도 파괴하면 원안의 살상·파괴 사건으로 집계한다. 제압으로 비살상 해결이 가능하다.
10. 보스 전투도 최종 비율에 포함한다. 보스를 반드시 비살상으로 끝내야 한다는 조건은 추가하지 않았다.
11. 제작 재료 예약은 소모가 아니다. 성공해야 전체 재료와 결과물이 함께 반영된다.
12. 필드 중독은 추가 피해를 주지 않는다. 전투 종료 이후 필드·휴식·중화 도구로 회복할 수 있다.

캠페인 경로 검사는 일반 플레이와 같은 사건 처리 함수를 호출한다. 전투 승리를 보장하도록 검증 중 HP를 보정하기 때문에 전투 난이도 검증으로 간주하지 않는다. 맵 접근성 검사는 0.5타일 간격 경로 탐색과 실제 조사 대상 판정을 사용한다. 전체 캠페인을 사람이 키보드로 처음부터 끝까지 플레이한 기록과는 다르다.

숨김 창으로 실행한 초기 독립 실행 검증에서는 화면 버퍼 캡처가 실패했다. 실제 게임 창을 표시한 실행에서는 기본 그래픽 경로와 Direct3D 11 경로 모두 6개 화면 캡처와 런타임 검사가 통과했다. 이 차이를 게임 진행 통과와 혼동하지 않는다.

## 완성도 평가에서 분리할 항목

- 기획의 2~3시간은 목표 분량이다. 현 빌드의 1회차 플레이 시간을 실측하여 달성했다고 주장하지 않는다.
- 보스의 8~12라운드는 설계 목표다. 해결법과 추가 효과 확률에 따라 훨씬 빠른 비살상 승리가 가능하므로 실제 밸런스 조정 대상으로 남는다.
- 픽셀 그래픽은 제공된 시트를 재해석해 코드로 제작한 기본 게임 자산이다. 원본 콘셉트의 세부 선화와 모든 미세한 특징을 그대로 옮긴 수작업 최종 아트가 아니다.
- 음원 생성과 재생 구성은 구현했다. 사람의 스피커·헤드폰 직접 청취, 장시간 반복의 피로도 평가는 별도다.
- 외부 사용자의 추리 이해도, 엔딩 납득도, 전투 선호도는 사용자 플레이테스트가 필요하다.
- Steam 배포·상점·업적 연동·서명·설치 프로그램은 원안의 PC 타깃과 별개인 출시 작업이며 이번에 외부 게시하지 않았다.

이 항목들은 실행 가능한 기능 구현과 구분하여 기록한다. 검증된 범위를 넘어 상용 출시 품질이나 목표 플레이 시간까지 완성했다고 표시하지 않는다.
