# 시작 화면 일러스트

2026-09-26 사용자의 요청에 따라 시작 화면에 2D 일러스트를 적용했다. 플레이 중 탐험과 전투의 3D 구성은 유지한다.

- 에셋: `Assets/Game/Resources/TitleIllustration.png`
- 참조: `resources/캐릭터 - 다은.png`, `캐릭터 - 제임스.png`, `캐릭터 - 다니엘.png`
- 제작: 위 세 이미지를 입력 참조로 사용한 이미지 생성. 원본 참조 파일은 변경하지 않았다.
- 반영 요소: 다은의 짧게 묶은 갈색 머리·흰 티·덧댄 작업복, 제임스의 금발·안경·긴 카디건, 다니엘의 붉은 머리·녹안·주근깨·가죽 어깨 패치.
- 구도: 연구소를 배경으로 오른쪽에 세 인물, 왼쪽에 어두운 제목·메뉴 여백. 그림에는 글자나 버튼을 넣지 않고 기존 Unity UI로 표시한다.
- 연결: `VirusGame.UI.cs`의 `TitleUI`. 가져오기는 `TitleArtImporter`에서 원본 비율 유지, 밉맵 해제, Bilinear 필터로 설정한다.
- 확인: Windows 실행 파일의 타이틀 캡처에서 메뉴와 일러스트 배치를 확인했다. 실행 스모크 검사 PASS, 오류 목록 없음.
