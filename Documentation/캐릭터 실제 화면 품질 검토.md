# 캐릭터 실제 화면 품질 검토

## 판단 기준

`CharacterModelSheet.png`는 2D 참고 그림이다. 모델 로딩·리깅 테스트 PASS를 원화 재현 품질 PASS로 사용하지 않는다. 실제 Unity 얼굴 확대, 전신 정면·사선·후면, 보행, 플레이 화면을 기준으로 검토한다.

## 이번 수정

- 눈 흰자의 노출과 동그랗게 드러난 홍채를 줄이고 눈꺼풀 안쪽으로 홍채를 제한했다.
- 턱 폭과 코의 돌출 형태, 눈썹 두께·위치를 수정했다.
- 앞머리 다발을 7개에서 12개로 나누고 폭·두께·끝 위치에 차이를 주었다. 겹침 잡음을 만들던 앞머리의 별도 선 메시를 제거했다.
- 얼굴 메시의 정점 색으로 눈 주변·볼·입술 부근의 색 변화를 넣었다.
- 피부 전용 음영과 캐릭터 셰이더의 주변광 처리를 조정해 셔츠의 밝은 면과 얼굴 명암이 과장되지 않도록 했다.
- 무릎·발목의 천 형태를 추가하고, 첫 검토에서 과했던 주름 진폭을 줄였다.
- 어깨 덮개 높이를 낮추되 피부가 밖으로 드러나지 않도록 의상 연결부를 수정했다.
- 탐색 렌더 타깃을 1920×1080, MSAA 4배로 변경했다. 카메라 시야각은 46도에서 42도로 조정했다.

## 실제 증거

- `Tools/character-quality-before/`: 이번 수정 전 캡처.
- `Tools/characters-daeun-face.png`, `characters-james-face.png`, `characters-daniel-face.png`: 실제 Unity 얼굴 확대.
- `Tools/characters-front.png`, `characters-threequarter.png`, `characters-back.png`, `characters-walk.png`: 실제 모델과 동작.
- `Tools/verification-character-quality-play.png`: Unity 실제 플레이 화면.
- `Builds/Windows/Verification/workshop.png`: Windows 실행 파일의 실제 공방 화면.

## 남은 미술 품질 차이

최종 기술 검증: 세 인물 24개 스킨 메시의 본·바인드포즈·가중치·변형 검사 통과, 14개 맵의 42개 주요 인물 배치 검사 통과. Windows 빌드 오류 0·경고 0, 실행 검사 PASS·오류 0이며 공방 캡처를 직접 확인했다. 이 결과는 아래의 미술 품질 차이가 해소됐다는 판정이 아니다.

현재 모델은 절차적 메시 기반의 스타일화된 캐릭터다. 참고 일러스트의 세밀한 얼굴 비대칭, 복잡한 머리 다발과 잔머리, 손으로 그린 명암과 의상 디테일까지 동등하게 재현했다고 보증하지 않는다. 이번 수정은 실제 자산과 렌더링의 개선이며, 원화 수준의 최종 미술 승인과 구분한다. 높은 해상도의 비용은 증가하므로 저사양 기기별 성능 보증도 별도 검증이 필요하다.
