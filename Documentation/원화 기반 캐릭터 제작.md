# 원화 기반 캐릭터 제작

## 범위와 기준

요청: 시작 화면의 세 캐릭터를 기준으로 인게임 캐릭터의 얼굴, 체형, 머리, 의상, 재질, 동작을 다시 구성한다. 대화창/HUD의 2D 일러스트 초상화는 유지한다.

기준 원화는 `Assets/Game/Resources/TitleIllustration.png`다. `resources`의 원본 파일은 수정하지 않았다.

## 이번 자산

- `ArtSource/Characters/CharacterModelSheet.png`: 세 인물의 정면·측면·후면과 얼굴·의상 상세를 정리한 기준 그림. imagegen으로 제작한 **디자인 참고 그림**이며 실제 3D 렌더가 아니다. 그림에 추가된 키나 영문 문구는 게임 설정으로 채택하지 않는다.
- `ArtSource/Characters/Daeun.blend`, `James.blend`, `Daniel.blend`: 메시, UV, 재질, 20개 본, 얼굴 형태 키를 포함하는 편집 가능한 Blender 원본.
- `Assets/Game/Resources/Characters/Daeun.fbx`, `James.fbx`, `Daniel.fbx`: Unity에서 실제 사용하는 모델.
- `Assets/Game/Resources/CharacterMaterialAtlas.png`: 머리카락 3종, 데님, 면, 카디건, 캔버스, 가죽의 8칸 재질 텍스처. Unity 전용 셰이더에서 UV 타일을 선택하며 색을 유지한 채 표면 변화를 적용한다.
- `ArtSource/Characters/build_characters.py`: Blender 제작·내보내기 스크립트. 곡면 모델링, 천 두께, 바지/다은 셔츠 접합부의 복셀 결합과 평활화, 명시적 스킨 가중치, 형태 키와 FBX 내보내기를 재현한다. 사람 모델러의 수작업 조각을 거쳤다는 의미는 아니다.

Blender 포터블은 [공식 배포 서버](https://download.blender.org/release/Blender4.5/)의 4.5.3 Windows 버전을 작업 폴더 `Tools/Blender`에 풀었다. 시스템 파일 연결이나 Unity 버전을 변경하지 않았으며 도구 폴더는 Git에서 제외했다.

## 재현

프로젝트 루트에서 PowerShell:

```powershell
& 'Tools/Blender/blender-4.5.3-windows-x64/blender.exe' --background --python ArtSource/Characters/build_characters.py
```

`-- --daeun`을 붙이면 다은만 내보낸다. `-- --render`를 붙이면 Blender 중립 조명 렌더도 저장한다. Blender 렌더는 Unity의 전용 재질 셰이더와 다른 조명 결과이며, 최종 게임 표현은 `Tools/characters-*.png`와 실행 파일 캡처로 확인한다.

이미지 생성은 내장 imagegen을 사용했다. 사용한 프롬프트 원문은 같은 원본 폴더의 `model-sheet-prompt.txt`, `material-atlas-prompt.txt`에 보관했다. 새로 생성한 이미지 두 개 모두 프로젝트 안에 저장했다.

## 품질 판정

원화의 인물별 복장과 색, 독립된 얼굴 구조 및 편집 가능한 제작 자산을 구현했다. 다만 모델 시트와 같은 수준의 세밀한 원화 재현을 완성했다고 판정하지 않는다. 얼굴의 개별 인상, 머리카락의 큰 덩어리와 옷의 실루엣에는 아직 차이가 있다. 표정은 제한된 기본 형태 키이며 음소별 립싱크나 표정 연기는 아니다. 메시 UV와 재질 아틀라스를 사용하지만 캐릭터별 전체 UV 손그림 텍스처를 제작한 상태는 아니다.

제작 기반의 구현 여부, 자동 검사의 통과 여부, 최종 미술 품질의 승인은 구분한다. 기준 그림을 실제 게임 결과처럼 제시하지 않는다.
