# 캐릭터 3D 개선 기록

2026-09-26. 사용자 지적: 인게임 캐릭터가 시작 화면 일러스트에 비해 지나치게 단순하다.

## 이번 구현

- 주인공 3명의 기본 도형 조합을 곡면 단면과 곡선으로 생성한 전용 메시로 교체했다. NPC 모델은 이번 교체 대상에 포함하지 않았다.
- 다은: 성인 체형, 갈색 묶음 머리, 흰 소매, 청색 멜빵바지, 버클, 바느질과 무릎 패치.
- 제임스: 금발, 푸른 눈, 입체 안경, 긴 어두운 카디건.
- 다니엘: 큰 체격, 붉은 머리, 녹색 눈과 주근깨, 가죽 어깨 장식, 붉은 안쪽 셔츠와 카고 주머니.
- 얼굴 일러스트를 곡면 머리 메시의 UV에 투영했다. 빌보드가 아니다. 머리카락, 귀, 손가락, 옷과 신발은 입체 메시다.
- 팔꿈치와 무릎의 2본 스키닝, 보행 굽힘, 대기 자세와 전투 동작을 연결했다.
- 인게임 카메라 거리와 HUD 초상화 카메라를 조정했다. 얼굴의 과도한 그림자를 줄이는 전용 셰이더를 적용했다.

## 이미지 자산

- 결과: `Assets/Game/Resources/CharacterFaceAtlas.png` (2172×724, 왼쪽부터 다은/제임스/다니엘).
- 제작: imagegen 도구에 `TitleIllustration.png`와 resources의 세 캐릭터 원본을 참조로 제공했다. 원본 자료는 변경하지 않았다.
- 프롬프트 구성 요약: 동일 크기의 정면 얼굴 세 칸, 성인 애니메이션풍, 다은의 갈색 눈과 따뜻한 피부, 제임스의 푸른 눈과 밝은 피부, 다니엘의 녹색 눈과 주근깨를 유지. 머리카락·귀·목·안경·문자 없이 피부색이 가장자리까지 이어지는 UV용 얼굴 텍스처. 이는 생성 당시 지시의 요약이며 원문 전체 전사는 아니다.

## 검증

- 3D 검사: 14개 맵, 94개 상호작용 콜라이더, 42개 캐릭터 배치 통과.
- 캠페인: 16개 진행 지점 통과.
- 이동 검사: 14개 맵의 94개 대상까지 충돌 없는 접근 경로 통과.
- 모델 검사: 총 16개 스킨 메시, 각 2개의 본과 바인드 포즈, 정규화된 가중치, 지원되는 셰이더 및 얼굴 텍스처 확인.
- `Tools/characters-front.png`, `characters-threequarter.png`, `characters-back.png`, `characters-walk.png`에 실시간 렌더 검수 이미지를 저장했다.
- 빌드 실행 검사의 최신 결과는 `Builds/Windows/Verification/runtime-report.json`을 확인한다.

## 품질 판정과 남은 작업

이 결과는 기존 임시 도형보다 체형과 얼굴의 식별성을 높인 개선 모델이다. 시작 화면 일러스트와 동등한 최종 아트 품질로 승인한 상태는 아니다. 특히 머리카락이 규칙적인 덩어리로 보이고, 옷의 주름·재질·접합부와 옆얼굴의 정교함이 부족하다. 표정용 블렌드셰이프와 전문 제작된 전신 리그도 없다. 최종 품질을 달성하려면 원화에 맞춘 세부 조형, UV/재질 작업과 애니메이션 정제가 더 필요하다. 자동 검사 통과는 이 미술적 품질 기준의 통과를 뜻하지 않는다.
